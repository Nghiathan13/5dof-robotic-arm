# 5-DOF Robotic Arm - AutoCAD Technical Drawing

This repository documents a final project for a 5-degree-of-freedom robotic arm modeled and drafted in AutoCAD.

The project focuses on mechanical component modeling and 2D technical drawing practice: representing the robotic arm assembly, documenting individual components, and preparing drawings that can be used as manufacturing or review references.

## CAD File

The final project drawing is included in this repository:

[cad/Final_project.dwg](cad/Final_project.dwg)

A view-only copy is also available on Google Drive:

[Google Drive - Final_project.dwg](https://drive.google.com/drive/folders/1jV9Q9WUAwnC9NrPf4IrIFqp03dnQIbj5?usp=sharing)

## Project Scope

The final drawing covers a 5-DOF robotic arm concept with mechanical parts modeled and documented in AutoCAD.

Main work included:

- Modeled a 5-DOF robotic arm and its individual mechanical components.
- Produced 2D technical drawings for component documentation.
- Organized views and drawing annotations for engineering review.
- Prepared the DWG file as the final submission for the technical drawing course/project.

1. Open `cad/Final_project.dwg` in AutoCAD or another DWG-compatible CAD viewer.
2. Review the overall robotic arm assembly first.
3. Inspect the individual component drawings and 2D views.
4. Use the Google Drive link if you prefer to download the original uploaded file.
