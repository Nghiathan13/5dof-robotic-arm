## Scope Boundary

This repository is limited to the final 5-DOF robotic arm drawing. Weekly assignments, homework files, and quiz drawings from the same local course folder are not included.

## Review Checklist

When reviewing the DWG file, check:

- Overall 5-DOF robotic arm layout.
- Individual component representation.
- Orthographic 2D views.
- Dimensioning and annotation clarity.
- Drawing organization for manufacturing/reference use.

## Tooling

Recommended tools:

- Autodesk AutoCAD.
- Autodesk DWG TrueView.
- Any DWG-compatible CAD viewer for read-only inspection.
